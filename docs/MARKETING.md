# 📣 AI-Сотрудник — маркетинговая стратегия

> **Продукт:** Telegram-бот «AI-Сотрудник» — виртуальный AI-ассистент для малого бизнеса: обрабатывает заявки 24/7, квалифицирует лидов, записывает на консультации, закрывает FAQ.
> **Тарифы:** Freemium (50 сообщ/мес) · Pro $29/мес · Business $99/мес · Enterprise $299/мес. Оплата — Telegram Stars.
> **ЦА:** малый бизнес, инфобизнес, консультанты, онлайн-школы, e-commerce (СНГ-рынок — приоритет).

---

## 1. Позиционирование и офферы по сегментам ЦА

**Общая рамка позиционирования:** «AI-Сотрудник — это не чат-бот с кнопками, а цифровой сотрудник, который понимает клиента, продаёт и записывает на консультацию. Стоит дешевле часа работы менеджера, окупается с первого же клиента.»

### 1.1 Малый бизнес (сервисы, салоны, локальный бизнес)
- **Заголовок:** «Не теряйте клиентов, пока вы заняты делом»
- **Подзаголовок:** «AI-Сотрудник отвечает на заявки за 10 секунд — вечером, ночью и в выходные. Клиент записан, вы спокойны.»
- **CTA:** «Запустить бесплатно за 5 минут» → `t.me/<bot>`

### 1.2 Инфобизнес (эксперты, продюсеры)
- **Заголовок:** «Каждый подписчик — деньги. Не упустите ни одного»
- **Подзаголовок:** «Бот встречает лида, квалифицирует его и продаёт слот на консультацию — без найма менеджеров и ручной обработки заявок.»
- **CTA:** «Подключить к своему боту»

### 1.3 Консультанты (юристы, психологи, коучи)
- **Заголовок:** «Личный администратор за $29/мес — без отпусков и больничных»
- **Подзаголовок:** «Записывает клиентов в ваше расписание, отвечает на вопросы о ценах и формате работы, напоминает о встречах. Вы занимаетесь только практикой.»
- **CTA:** «Дать боту поработать бесплатно»

### 1.4 Онлайн-школы
- **Заголовок:** «Отдел продаж для школы — без найма и окладов»
- **Подзаголовок:** «AI-Сотрудник консультирует по программе, отсеивает «туристов» и передаёт тёплых лидов кураторам. Конверсия из заявки в оплату — до +30%.»

## 2. Стратегия запуска: 3 фазы

### Фаза 1. Закрытая бета — недели 1–4
- **Цель:** 100 пользователей, из них ≥ 30 активированных, 3 оформленных кейса, 20+ отзывов.
- **Механика:** инвайт-коды через личные сети и профильные чаты, 5–10 посевов в микро-каналах, ручной онбординг основателем (личные созвоны с первыми 20 клиентами).
- **KPI:** Activation Rate ≥ 40%, NPS ≥ 50, время до первого ответа AI ≤ 3 мин.

### Фаза 2. Публичный запуск — недели 5–12
- **Цель:** 2 500 пользователей, 500+ активированных, 80 платящих, MRR ≈ $2 000.
- **Механика:** посевы в 30+ каналах, запуск реферальной программы, листинги в каталогах ботов (TGStat, Telemetr, botlist), кейсы в Telegram-медиа и на vc.ru, открытие Telegram-канала с контент-планом (раздел 4).
- **KPI:** CAC пользователя ≤ $1, Free→Paid ≥ 4%, D7 retention ≥ 35%.

### Фаза 3. Масштабирование — месяцы 4–6
- **Цель:** 12 000 пользователей, 700+ платящих, MRR ≈ $12 000.
- **Механика:** Telegram Ads на постоянной основе, партнёрская программа с инфопродюсерами (rev-share 25–30%), white-label для агентств, локализация для Казахстана/Беларуси/Узбекистана, приоритетная разработка фич для Enterprise.
- **KPI:** CAC платящего ≤ $15, LTV/CAC ≥ 3, churn ≤ 6%/мес.

## 3. Каналы привлечения

### 3.1 Telegram Ads
- Запуск через официальных реселлеров (порог входа ниже прямого): CPM в СНГ ≈ $0.6–2.0.
- Таргет: подписчики каналов по темам «малый бизнес», «маркетинг и продажи», «инфобизнес», «психология», «E-com».
- Креативы: карусель «до/после» (скрин диалога клиента с ботом), видео 15 сек «клиент пишет в 2 ночи — бот отвечает и записывает».
- **Ожидания:** CPC $0.05–0.12, стоимость подписчика бота $0.3–0.8.

### 3.2 Посевы в каналах
- Список 100 каналов по ЦА (через TGStat/Telemetr), 3 эшелона: топ (100k+), мидл (20–100k), микро (5–20k).
- Форматы: нативный кейс (пост 1) → промо-пост с оффером (пост 2) в том же канале.
- Тест: 3–5 публикаций на эшелон, масштабируем только каналы с CPL ≤ $0.5.

### 3.3 Партнёрства с инфопродюсерами
- Rev-share 25–30% с платежей приведённых клиентов, персональный дашборд статистики.
- Продюсеру — бесплатный Enterprise + white-label (бот под брендом его школы).
- Совместные вебинары «Как автоматизировать продажи в Telegram» + промокоды для аудитории.

### 3.4 SEO в Telegram и внешнее
- Имя/username с ключами: «AI-Сотрудник — AI-ассистент для бизнеса», описание бота с ключами: «бот для записи клиентов», «чат-бот для малого бизнеса», «обработка заявок 24/7».
- Индексация: каталоги ботов, статьи на vc.ru/Habr («Как перестать терять заявки ночью»), YouTube Shorts/TikTok с демо-скринами, ответы в Яндекс.Кью / профильных чатах.

### 3.5 Реферальная программа (конкретная механика)
1. В меню бота — кнопка **«Позвать друга»** → персональная ссылка `t.me/<bot>?start=ref_{user_id}`.
2. Друг переходит и пишет боту → пригласившему **+20 сообщений** к месячному лимиту (зачёт после `/start` и первого сообщения друга — антифрод).
3. Друг покупает любой платный тариф → пригласившему **+100 сообщений** или 1 месяц Pro бесплатно (на выбор).
4. Бонусные сообщения переносятся, но накопление ограничено 500/мес (антиабьюз).
5. Экран рефералки: прогресс-бар «Приглашено 3 / Купили 1» + кнопка «Поделиться в Telegram» (нативный share).
- **Прогноз:** K-factor 0.15–0.3 при среднем 2.1 приглашении на активного пользователя.

## 5. Growth hacking

### 5.1 Вирусные механики
- **«Карточка экономии»:** раз в месяц бот генерирует красивую карточку «AI-Сотрудник ответил на 312 сообщений и записал 24 клиентов» с водяным знаком — клиент шерит её в чаты и сторис.
- **Публичные ответы:** при работе в группах бот подписывается брендом → органические переходы от каждого ответа.
- **«Подарить сообщения»:** можно отправить другу 10 сообщений из своего лимита — друг знакомится с продуктом бесплатно.
- **Калькулятор упущенной выгоды:** квиз «Сколько вы теряете, не отвечая ночью?» → шокирующая цифра за год → CTA «Проверить бесплатно».
- **Лестница прогресса:** «Ваш AI-Сотрудник вышел на уровень “Старший менеджер”» — геймификация стажа и обработанных сообщений.

### 5.2 Лид-магниты
- **Бесплатный аудит ответов бизнеса:** клиент присылает свои FAQ → AI анализирует и присылает PDF: 5 ошибок, 3 улучшенных ответа, скрипт записи. В конце документа — оффер на триал. Это главный лид-магнит: конвертирует 25–40% в активацию.
- PDF «50 реальных вопросов клиентов + идеальные ответы» (за подписку на канал).
- Набор шаблонов сценариев записи и квалификации для 5 ниш (сервисы, школы, консультанты, e-com, инфобизнес).

### 5.3 Кейсы (структура + эталон)
- Шаблон: Проблема → Решение → Цифры за 30 дней → Цитата клиента → CTA.
- Эталон: «Онлайн-школа английского: заявки ночью обрабатывались утром, −40% лидов терялось → подключили Business ($99) → AI квалифицирует и записывает на пробный урок → конверсия в оплату +27%, окупаемость — 1 неделя».
- Цель: 3 кейса в бете, 10 к концу месяца 3; каждый кейс = пост в канале + посев + лендинг-блок.

## 7. Аналитика

### 7.1 События для трекинга
| Событие | Момент фиксации | Зачем |
|---|---|---|
| `bot_start` | Первый `/start` | Вход в воронку, источник (utm/ref в `start_payload`) |
| `role_selected` | Выбор ниши | Сегментация ЦА, персонализация контента |
| `knowledge_uploaded` | Загрузка FAQ | Лид-актив, предиктор активации |
| `aha_moment` | Показ первого AI-ответа | **Ключевое событие активации** |
| `connected_to_chat` | Бот добавлен в рабочий чат/канал | Переход «в бой» |
| `first_client_message` | Первый диалог с реальным клиентом | Real value |
| `ref_invite_sent` / `ref_friend_joined` / `ref_friend_paid` | Реферальная механика | K-factor, виральность |
| `limit_warning_view` | 80% лимита Free | Предвестник paywall |
| `paywall_view` | Открытие экрана тарифов | Конверсия в покупку |
| `checkout_start` | Выбор тарифа | Падение между выбором и оплатой |
| `purchase` | Успешный платёж Stars (`tariff`, `amount_stars`) | Выручка, LTV |
| `subscription_renewed` / `churn` | Продление / отписка | Retention, churn |

### 7.2 Инструменты
- **Продуктовые события:** PostHog (или Amplitude/Mixpanel) — воронки, когорты, retention-матрицы.
- **Attribution:** deeplink-параметры `?start=src_*` для Telegram Ads, посевов, рефералов.
- **Дашборды:** Telegram Bot API логи + Metabase/Grafana; аналитика канала — TGStat, Telemetr.
- **Фидбек:** NPS-опрос на 7-й день активным пользователям, exit-опрос при отписке.

### 7.3 Ключевые метрики
- **Activation Rate** = `aha_moment` / `bot_start` — цель ≥ 40% (North Star).
- **Time-to-Aha** ≤ 3 минуты от `/start`.
- **Free→Paid** ≥ 5% к 3-му месяцу; **CAC платящего** ≤ $15; **LTV** ≥ $90; **churn** ≤ 6%/мес.
